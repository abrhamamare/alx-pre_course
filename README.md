# ALX Pre-Course Exercises

Introductory Git, shell, and repository-management exercises from ALX.

## Technologies and topics

Git, shell basics, version control.

## Getting started

Explore the `0x01-git` and `bash` directories and read the exercise files before running commands.

## Repository organization

Browse the source files and topic directories for individual examples. Some exercises are standalone and should not be compiled together.

## Technical interview discussion

Git branching, commits, basic shell navigation, and collaborative workflows.

## Scope

Educational coursework and practice code. This repository is not claimed to be production-ready or security-audited.
